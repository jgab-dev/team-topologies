# Team Topologies — Key Points

A 25-slide summary deck of *Team Topologies, 2nd Edition* (Matthew Skelton &
Manuel Pais, IT Revolution, 2025), covering the four fundamental team types,
the three team interaction modes, cognitive load, Conway's Law, fracture
planes, and what's new in the 2nd edition.

## Files

- `team-topologies.md` — the deck source, written as Markdown slides
  separated by `---`.
- `team-topologies.html` — a self-contained HTML viewer for the same deck.
  Open it directly in a browser, or serve the folder (e.g. via GitHub Pages)
  to view it online. Arrow keys / swipe to navigate, `f` to toggle
  fullscreen.
